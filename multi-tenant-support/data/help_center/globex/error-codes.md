# Thermostat error codes

E1: the room sensor is not responding. Replace the sensor battery (CR2032).
E4: the thermostat gets no constant power. Check that the C-wire is connected to the C terminal on both the thermostat and the boiler.
E7: Wi-Fi connection lost. Restart your router, then hold the dial for 5 seconds to reconnect.

If an error comes back within 24 hours, open a support ticket and include the error code.
