# Reset the S2 base station

Reset the base station when the vacuum no longer docks or the status light blinks orange.

1. Unplug the base station and wait 30 seconds.
2. Hold the Home button on the vacuum for 10 seconds until it beeps twice.
3. Plug the base station back in and place the vacuum on the charging contacts.

The status light turns solid white when the reset worked. If it keeps blinking orange, note the error code on the display and open a support ticket.
